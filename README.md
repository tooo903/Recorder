# FPS Recorder

Приложение для записи экрана с контролем трёх вещей, из-за которых обычные
рекордеры дают "плавающие" 60 вместо реальных 72-90:

1. **Жёстко фиксирует частоту обновления экрана** (90Hz) на время записи —
   система (EMUI) часто тихо занижает её до 60Hz при активном MediaProjection.
2. **Показывает реальный лимит аппаратного видеокодека** твоего SoC (Adreno 610 /
   Venus) для каждого разрешения и кодека — если энкодер физически не тянет
   90fps на 1080p, приложение скажет это прямо, а не будет тихо откатываться на 60.
3. **Задаёт кодеку постоянный, а не "естественный" темп кадров** через
   `KEY_REPEAT_PREVIOUS_FRAME_AFTER` — это убирает микро-рывки/джиттер, который
   ощущается как "будто не 70+ FPS", даже когда цифра формально выше 60.

## Важно понимать заранее

Кнопка "Проверить реальный лимит кодека" — самая важная часть. Открой
приложение и нажми её **до** того, как пытаться писать в 90fps. Если она
покажет "НЕ хватает" на всех вариантах — это железное ограничение видеоблока
Snapdragon 680, и никакое приложение (моё или чужое) физически не обойдёт это
программно. В таком случае реальный путь — снижать разрешение записи до 720p,
там лимиты кодеков обычно выше.

## Сборка через Termux + Gradle

```bash
pkg update && pkg upgrade
pkg install openjdk-17 gradle git

git clone <твой-репозиторий-на-github> fps-recorder
cd fps-recorder

# Нужен Android SDK — самый простой путь в Termux:
pkg install android-tools
# Или скачай command-line tools вручную и пропиши ANDROID_HOME
export ANDROID_HOME=$HOME/android-sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools

gradle assembleDebug
```

Собранный APK будет в `app/build/outputs/apk/debug/app-debug.apk`.
Установи его через `pkg install android-tools` → `adb install app-debug.apk`,
либо просто скопируй APK на телефон и установи вручную (разреши установку
из неизвестных источников).

## Как пользоваться

1. Открой приложение → нажми "Проверить реальный лимит кодека" для нужного FPS
2. Если лимит позволяет — жми "Выдать разрешение на изменение настроек экрана"
   (откроется системная настройка, включи переключатель для этого приложения)
3. Выбери FPS/разрешение/кодек → "Начать запись" → разреши захват экрана
4. Сверни приложение, играй в Standoff 2 — запись идёт в фоне
   (foreground-сервис с уведомлением)
5. Разверни приложение → "Остановить запись". Файл лежит в
   `Android/data/com.fpsrecorder.app/files/fps_record_*.mp4`

## Если после всего этого всё равно 60

Значит дело в аппаратном энкодере — проверь вывод кнопки "Проверить реальный
лимит кодека". Это не программируемо обходится, это железо SD680.
Единственные рабочие пути в этом случае: писать в 720p (там лимиты кодеков
почти всегда выше), либо использовать внешнюю запись (второй телефон/капча
через USB-C), которая вообще не грузит твоё устройство.
